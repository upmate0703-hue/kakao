# 카카오 발송기 (KakaoRoomScheduler)

Windows PC 카카오톡의 채팅방 목록을 읽어 발송 대상을 고르고, 같은 문구와 사진·파일을 한 번에 또는 예약한 시각에 보내는 보조 프로그램입니다.

카카오 계정·비밀번호·인증정보는 사용하지 않고 저장하지도 않습니다. 화면에 이미 로그인된 PC 카카오톡을 사람처럼 클릭해서 동작합니다.

---

## 빠른 시작

1. PC 카카오톡에 로그인하고 채팅 목록이 보이게 창을 띄웁니다. (최소화되어 있으면 안 됩니다)
2. `Start-KakaoRoomScheduler.cmd`를 더블클릭합니다.
3. 처음 실행하면 **가이드 투어**가 자동으로 뜹니다. 7단계를 따라가면 준비가 끝납니다.
4. 가이드는 오른쪽 위 **`?` 버튼**이나 `설정 → 가이드 다시 보기`로 언제든 다시 볼 수 있습니다.

> **좌표를 맞추는 설정은 없습니다.** 예전 버전에 있던 `① 채팅탭 ② 검색창 ③ 첫 검색결과` 보정 과정은 사라졌습니다.
> 카카오톡 창의 내부 구조를 실행할 때마다 읽어 검색창과 목록 위치를 스스로 찾습니다.
> `설정 → 카카오톡 연결 상태`에서 지금 잘 연결됐는지 한눈에 확인할 수 있습니다.

## 화면 구성

| 화면 | 하는 일 |
| --- | --- |
| **발송 준비** | 보낼 문구 작성, 사진·파일 첨부와 순서 조정 |
| **채팅방 선택** | 방 목록 읽기, 종류(일반/오픈) 분류, 그룹 묶기, 이름 수정·직접 추가 |
| **실행 · 예약** | 발송 방식, 테스트 발송, 발송 제한(방해금지·주말·공휴일), 지금 실행 / 예약 |
| **설정** | 카카오톡 연결 상태 확인, 탭 위치 알려주기, 업데이트, 가이드 다시 보기 |
| **실행 기록** | 성공·건너뜀·오류 기록 확인 |

## 1단계 · 카카오톡 연결 확인

`설정 → 카카오톡 연결 상태 → 지금 확인`을 누르면 아래를 점검해 보여 줍니다.

- 카카오톡 창을 찾았는지, 지금 어떤 화면을 보고 있는지 (`ChatRoomListView` 등)
- 채팅 목록과 검색창을 찾았는지
- 한국어 문자 인식을 쓸 수 있는지

세 줄이 모두 `[정상]`이면 바로 쓸 수 있습니다. 창 크기를 바꿔도 다시 설정할 필요가 없습니다.

### 탭 위치 알려주기 (선택)

평소에 카카오톡을 보낼 탭에 두고 쓰신다면 필요 없습니다.
프로그램이 `채팅`↔`오픈채팅` 탭을 **자동으로 전환**하게 하려면 한 번만 알려 주세요.

`채팅 탭 위치 알려주기`를 누르면 카카오톡이 앞으로 나옵니다. 왼쪽 세로 줄에서 **평소처럼 [채팅] 아이콘을 한 번 클릭**하면 그 자리를 기억합니다. `오픈채팅`도 같은 방법입니다.

알려 주지 않아도 동작합니다. 그때는 해당 탭을 직접 열어 둔 상태에서 실행하면 됩니다.

---

## 2단계 · 채팅방 목록 읽기

`채팅방 선택 → 카카오톡에서 읽기`를 누르면 **지금 카카오톡에서 보고 있는 탭**의 목록을 아래로 넘기며 방 이름 후보를 모읍니다.

### 일반 채팅과 오픈채팅 나눠 읽기

`카카오톡에서 읽기`를 누르면 **지금 읽는 목록이 일반 채팅인지 오픈채팅인지 먼저 물어봅니다.**
카카오톡 내부 화면 이름으로 자동 판별한 결과를 함께 보여 주니 그대로 답하면 됩니다.

1. 카카오톡에서 `채팅` 탭을 보고 → `카카오톡에서 읽기` → `아니오(일반 채팅)`
2. 카카오톡에서 `오픈채팅` 탭으로 바꾸고 → `카카오톡에서 읽기` → `예(오픈채팅)`

목록 위의 `전체 / 일반채팅 / 오픈채팅` 버튼으로 걸러 볼 수 있고, 발송할 때는 같은 종류끼리 묶어 탭 전환을 최소화합니다.

> 오픈채팅 탭은 카카오톡이 **처음 눌렀을 때 비로소 만드는** 화면입니다. 한 번도 누른 적이 없으면 프로그램이 그 화면을 찾을 수 없으니, 카카오톡에서 직접 오픈채팅 탭을 눌러 목록을 띄운 뒤 읽어 주세요.

### 그룹으로 묶어 쓰기

자주 보내는 방들을 그룹으로 저장해 두면 다음부터 한 번에 고를 수 있습니다.

1. 보낼 방들을 체크합니다.
2. `새 그룹 만들기`를 누르고 이름을 정합니다. (예: 학부모, 홍보방)
3. 다음에는 그룹을 고르고 `이 그룹 체크`만 누르면 됩니다.

`체크한 방 넣기`로 기존 그룹에 더 넣을 수 있고, `그룹 삭제`는 그룹만 지우며 채팅방 목록은 그대로 남습니다.

### 어떻게 읽나요

카카오톡은 채팅 목록을 직접 그리기 때문에 Windows 접근성 정보(UI Automation·MSAA)로는 방 이름이 전혀 노출되지 않습니다. 그래서 이 프로그램은 **채팅 목록 영역을 그대로 캡처해 Windows 내장 한국어 OCR로 글자를 읽습니다.**

- `PrintWindow`로 캡처하므로 카카오톡이 다른 창에 가려져 있어도 읽을 수 있습니다.
- 목록 스크롤도 컨트롤에 휠 신호를 직접 보내는 방식이라 **실제 마우스를 움직이지 않습니다.**
- 한 화면에 보이는 행 수만큼만 내려 겹침을 줄입니다. 참고로 100개 남짓한 방을 약 10초에 읽습니다.
- 각 행 오른쪽의 시각 표기(`오후 3:20`, `어제` 등)를 기준선 삼아 같은 높이의 왼쪽 글자를 방 이름으로 골라냅니다.
- 접근성 정보로 읽히는 카카오톡 버전이라면 그 방식도 자동으로 함께 시도합니다.
- 한국어 OCR 언어 팩이 없으면 읽기가 실패합니다. `설정 → 시간 및 언어 → 언어 및 지역`에서 한국어의 선택적 기능 중 `광학 문자 인식`을 설치하세요.

### 읽은 뒤 반드시 할 일

화면 글자를 읽는 방식이라 **이름이 조금씩 틀릴 수 있습니다.** 그래서 두 단계로 씁니다.

1. 보낼 방만 체크합니다.
2. `이름 확인·보정`을 누릅니다. 체크한 방을 하나씩 열어 **실제 채팅창 제목으로 자동 교정**합니다.

- 이 과정에서 채팅방이 열리므로 읽음 표시가 될 수 있습니다. 메시지는 전송하지 않습니다.
- 그래도 안 잡히는 방은 `직접 추가`로 정확히 입력하거나 `이름 수정`으로 고칩니다.
- **동명 채팅방은 구분되지 않습니다.** 카카오톡에서 방 이름을 서로 다르게 바꾼 뒤 사용하세요.
- `최대 탐색 페이지`로 목록을 얼마나 깊게 넘길지 정할 수 있습니다(기본 20).
- 읽는 동안에는 마우스와 키보드를 사용하지 마세요.

이름이 틀린 채로 남아 있어도 안전합니다. 발송 직전에 열린 채팅창 제목이 정확히 일치하는지 다시 확인하고, 다르면 전송하지 않고 건너뜁니다.

## 3단계 · 테스트 모드로 먼저 확인

실제 발송 전에 반드시 테스트하세요. `실행 · 예약` 화면에 두 가지 안전장치가 있습니다.

**테스트 발송** — 지정한 **한 방에만** 실제와 똑같이 문구와 첨부를 보냅니다.
기본값은 `나와의 채팅`이라 아무에게도 전달되지 않으면서, 줄바꿈·사진 순서를 눈으로 확인할 수 있습니다.
방 이름은 직접 입력해도 되고 `목록에서 고르기`로 저장된 목록에서 골라도 됩니다.

**방 확인만** — 채팅창을 열어 제목이 정확히 일치하는지만 확인하고 전송하지 않습니다.

또한 발송 방식에서 `확인 전용`을 고르면, 선택한 **모든** 방을 하나씩 열어 이름만 검사하고 전송하지 않습니다. 전체 목록이 맞는지 점검할 때 쓰세요.

## 4단계 · 실행과 예약

- `지금 실행` — 바로 발송합니다.
- `예약 시작` — 지정한 시각에 자동 발송합니다.
- `예약 취소` — 대기 중인 예약을 해제합니다.

예약 실행 조건:

- 예약 시각까지 이 프로그램과 PC 카카오톡을 모두 켜 두어야 합니다.
- Windows가 잠금·절전·화면 보호 상태이면 화면 자동화가 동작하지 않습니다.
- 실행 중에는 마우스와 키보드를 사용하지 마세요.
- 카카오톡 창 크기와 화면 배율을 보정했을 때와 같게 유지하세요.

### 발송 제한 (방해금지 · 주말 · 공휴일)

`실행 · 예약 → 발송 제한`에서 보내지 않을 때를 정할 수 있습니다.

- **방해금지 시간대** — 예: `21:00` 부터 `08:00` 까지. 자정을 넘는 구간도 됩니다.
- **주말(토·일)에는 보내지 않기**
- **공휴일에는** `평소대로` / `보내지 않음` / `간격 늘리기`(배수 지정)

동작 방식:

- `지금 실행`이 제한에 걸리면 이유와 다음 가능 시각을 보여 주고 한 번 더 확인합니다.
- `예약 실행`이 제한에 걸리면 **취소하지 않고 보낼 수 있는 다음 시각으로 미룹니다.**
- 발송 도중 방해금지 시간대로 들어가면 남은 방은 보내지 않고 멈추며, 기록에 남깁니다.
- 카드 아래에 오늘 날짜·공휴일 여부·지금 보낼 수 있는지·적용될 간격이 항상 표시됩니다.

공휴일은 양력 고정일과 **음력 명절(설날·추석·부처님오신날)** 을 Windows 음력 달력으로 계산하고, 주말과 겹칠 때의 대체공휴일도 반영합니다. `올해 공휴일 보기`로 실제 목록을 확인하세요. 임시공휴일은 자동으로 알 수 없으므로 필요하면 `config.json`의 `ExtraHolidays`에 `"2026-10-16"` 형식으로 추가하면 됩니다.

안전장치:

- 방 사이 간격 최소 5초, 한 작업 최대 50개 방
- 검색해서 열린 채팅창 제목이 정확히 일치할 때만 전송 (`방이름` 또는 `방이름 (인원수)`)
- 첨부 파일이 하나라도 없으면 실제 실행 전에 중단
- 실제 발송 직전 대상 개수와 첨부 개수를 보여 주고 한 번 더 확인

## 자동 저장

입력을 멈추면 약 0.8초 뒤 자동 저장되고, 창을 닫을 때 한 번 더 저장됩니다.

저장 항목: 선택한 방과 읽어온 방 후보, 문구, 첨부 경로와 순서, 예약 시각, 방 간격, 발송 방식, 탐색 페이지 수, 테스트 방 이름, 화면 보정 위치, 가이드 표시 여부.

저장 위치는 프로그램 폴더의 `config.json`입니다. 이 파일은 이 PC 안에만 있으며 저장소에 올라가지 않습니다.

## 업데이트

`설정 → 업데이트`에서 GitHub 저장소의 최신 배포본을 확인합니다.

- `시작할 때 자동 확인`이 켜져 있으면 실행 직후 조용히 확인합니다.
- `새 버전이 있으면 물어보고 바로 받기`가 켜져 있으면, 새 버전이 발견되면 변경 내용을 보여 주고 **확인 한 번으로 내려받기 → 설치 → 재시작**까지 진행합니다.
- 왼쪽 아래 노란 알림이나 `업데이트 확인` 버튼을 눌러도 같은 흐름으로 이어집니다.
- 기존 파일은 `backup\날짜-시각\` 폴더에 보관되며, `config.json`과 `logs`는 그대로 유지됩니다.
- `저장소 열기`로 변경 내용을 직접 확인할 수도 있습니다.

## 배포하기 (관리자용)

어디서든 — 심지어 휴대폰 브라우저에서도 — 수정하고 배포할 수 있습니다.

### 방법 A · GitHub 웹에서 (설치 불필요)

1. GitHub 저장소에서 파일을 열고 연필 아이콘으로 수정한 뒤 커밋합니다.
2. `Actions` 탭 → `release` 워크플로 → `Run workflow`를 누릅니다.
3. 버전(예: `3.1.0`)과 변경 내용을 입력하고 실행합니다.

워크플로가 스크립트에 버전을 기록하고, 커밋·태그·압축·릴리스 등록까지 자동으로 처리합니다.

### 방법 B · 이 PC에서 명령 한 줄

```powershell
.\Publish-Release.ps1 -Version 3.1.0 -Notes "채팅방 읽기 정확도 개선"
```

자체 점검 → 커밋·푸시 → 워크플로 실행까지 한 번에 진행합니다. `git`과 `gh`(GitHub CLI 로그인 완료)가 필요합니다.

### 방법 C · 태그 푸시

```bash
git tag v3.1.0 && git push origin v3.1.0
```

어떤 방법을 쓰든 결과는 같습니다. 사용자는 프로그램의 `업데이트 확인`에서 새 버전을 받게 됩니다.

> 스크립트는 **UTF-8 BOM**으로 저장해야 합니다. PowerShell 5.1은 BOM이 없으면 한글을 깨뜨립니다. GitHub 웹 편집기는 기존 인코딩을 유지하므로 그대로 수정해도 안전합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `Start-KakaoRoomScheduler.cmd` | 실행 파일 (더블클릭) |
| `KakaoRoomScheduler.ps1` | 프로그램 본체 |
| `Publish-Release.ps1` | 이 PC에서 배포를 실행하는 스크립트 |
| `.github/workflows/release.yml` | GitHub 자동 배포 워크플로 |
| `config.json` | 자동 저장 설정 (저장소에 올라가지 않음) |
| `logs\YYYY-MM-DD.log` | 날짜별 실행 기록 |
| `backup\` | 업데이트 전 파일 백업 |

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 카카오톡 창을 찾지 못함 | PC 카카오톡이 실행 중이고 최소화되지 않았는지 확인. `설정 → 지금 확인`으로 진단 |
| 테스트 발송이 실패함 | `설정 → 지금 확인`이 모두 `[정상]`인지 먼저 확인. 그다음 방 이름이 카카오톡 표시와 정확히 같은지 확인 |
| 방을 못 열고 계속 건너뜀 | 체크한 뒤 `이름 확인·보정`을 실행하세요 |
| 목록을 읽었는데 0개 | 카카오톡에서 채팅 목록이 보이는 상태인지 확인. 한국어 문자 인식 설치 여부도 확인 |
| 오픈채팅방이 안 읽힘 | 카카오톡에서 `오픈채팅` 탭으로 바꾼 뒤 `카카오톡에서 읽기`를 다시 누르세요 |
| 목록에 이상한 문구가 섞임 | 화면 글자를 읽는 방식이라 정상입니다. 체크 후 `이름 확인·보정`으로 정리하세요 |
| 클립보드 오류 | 다른 프로그램이 클립보드를 점유 중입니다. 잠시 후 다시 시도 |
| 한글이 깨져 보임 | 스크립트가 UTF-8 BOM으로 저장되었는지 확인 |
| 업데이트 확인 실패 | 인터넷 연결과 회사망 방화벽(api.github.com) 확인 |

## 개발자 명령

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\KakaoRoomScheduler.ps1 -SelfTest
```

설정 스키마, 방 이름 필터, 화면 읽기 행 분리, 창 제목 비교, 버전 비교, 가이드 내용을 점검하고 `SELFTEST_OK`를 출력합니다. 배포 스크립트가 자동으로 실행합니다.

```bash
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\KakaoRoomScheduler.ps1 -ScanTest
```

창을 띄우지 않고 채팅방 목록 읽기만 실행해 결과를 확인합니다. 이름을 가리려면 `-MaskNames`를 함께 붙이세요.

## 사용 시 유의

수신에 동의한 분들이 있는 채팅방에서만 사용하세요. 반복적인 대량 발송은 카카오톡 이용 제한의 원인이 될 수 있으며, 그 책임은 사용자에게 있습니다.

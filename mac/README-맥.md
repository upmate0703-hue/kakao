# 카카오 발송기 (맥용) v0.1

Windows 판과 **같은 프로그램이 아닙니다.** 맥 카카오톡은 화면 구조가 완전히 달라서 새로 만들어야 하고, 지금은 **첫 단계**입니다.

---

## 지금 어디까지 왔나

**솔직히 말씀드립니다.** 이 맥용 도구는 **아직 실제 맥에서 확인되지 않았습니다.**

Windows 판을 만들 때, 제가 화면 구조를 추측한 것은 **거의 다 틀렸습니다.**

- 접근성 정보로 방 이름을 읽을 수 있을 줄 알았지만 → 하나도 안 나왔습니다
- 목록 위 줄이 검색창인 줄 알았지만 → 필터 버튼 줄이었습니다
- `Ctrl+V`로 붙여넣기가 될 줄 알았지만 → 아예 막혀 있었습니다

전부 **실제로 돌려 보고서야** 알았습니다. 맥에서도 똑같을 것입니다. 그래서 이 도구는 **먼저 구조를 확인하고, 확인된 것만 자동화**하는 순서로 만들었습니다.

한 가지 기대할 만한 점은 있습니다. **맥 앱은 보통 접근성 정보를 잘 내놓습니다.** Windows 카카오톡은 목록을 직접 그려서 글자를 하나도 안 내놨지만, 맥은 방 이름을 그대로 읽을 수 있을 가능성이 높습니다. 그러면 **화면 글자 인식(OCR) 없이** 훨씬 정확하고 빠르게 동작합니다.

---

## 준비

### 1. 파일 두 개를 같은 폴더에 두기

```
카카오톡봇-맥.command
kakao-mac.js
```

### 2. 실행 권한 주기

터미널을 열고 (`응용 프로그램 → 유틸리티 → 터미널`):

```bash
cd 파일이_있는_폴더
chmod +x 카카오톡봇-맥.command
```

### 3. 손쉬운 사용 권한 켜기 (필수)

다른 앱 화면을 읽고 조작하려면 맥이 허락해야 합니다.

`시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용` 에서 **터미널**을 켜 주세요.

이 권한이 없으면 **아무것도 동작하지 않습니다.**

### 4. 카카오톡 켜기

맥 카카오톡에 로그인하고, 채팅 목록이 보이게 창을 띄워 둡니다.

---

## 쓰는 순서

`카카오톡봇-맥.command` 를 두 번 누르면 메뉴가 나옵니다.

```
1) 쓸 수 있는 상태인지 확인
2) 카카오톡 화면 구조 저장   ← 처음에 이것부터
3) 채팅방 목록 읽기
4) 방 하나 열어 보기
5) 보내기 연습 (실제로 안 보냄)
6) 실제로 보내기
```

### 1번 → 2번 순서로 해 주세요

**1번**으로 권한과 카카오톡이 준비됐는지 봅니다.

**2번**이 가장 중요합니다. 카카오톡 화면 구조를 `카카오톡-화면구조.txt` 파일로 저장합니다. **이 파일을 저에게 보내 주시면**, 맥 카카오톡의 실제 구조에 맞게 고칠 수 있습니다. Windows 판도 이 과정을 거쳐 동작하게 됐습니다.

**3번**이 방 이름을 제대로 읽어 오면, 맥 판은 Windows 판보다 오히려 간단해집니다.

---

## 안전장치

Windows 판과 같은 원칙입니다. **틀리면 보내지 않습니다.**

- **5번(연습)이 기본입니다.** 글을 입력칸에 넣어 보고 **비운 뒤 끝냅니다.** 실제로 보내지 않습니다.
- **6번(실제 전송)은 `예` 라고 직접 입력해야** 진행됩니다.
- 입력칸에 넣은 글을 **다시 읽어 확인**하고, 보낼 글과 다르면 **전송하지 않습니다.**
- 전송 성공은 **입력칸이 비워졌는지**로 판단합니다. 안 비워졌으면 실패로 알리고 입력칸을 정리합니다.

---

## 아직 없는 것

Windows 판에 있는 아래 기능은 **아직 없습니다.**

예약·반복 발송, 묶음 발송, 방해금지·공휴일 설정, 그룹 관리, 사진 첨부, 화면(GUI), 자동 업데이트

먼저 **방 목록 읽기와 한 건 보내기**가 확실히 되는지 확인한 뒤에 얹는 것이 맞습니다. 그게 안 되는 상태에서 위 기능을 만들어 봐야 소용이 없습니다.

수신에 동의한 분들이 있는 채팅방에서만 사용하세요. 반복적인 대량 발송은 카카오톡 이용 제한의 원인이 될 수 있으며, 그 책임은 사용자에게 있습니다.

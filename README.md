# 카카오 발송기 사용 설명서

PC 카카오톡의 채팅방 여러 곳에 같은 문구와 사진을 한 번에, 또는 예약한 시각에 보내 주는 프로그램입니다.

카카오 계정·비밀번호·인증정보는 **쓰지도 저장하지도 않습니다.** 이미 로그인된 PC 카카오톡을 대신 조작할 뿐입니다.

## 처음 시작하기

### 준비물

- Windows 10 이상
- PC 카카오톡 (로그인된 상태)
- **한국어 문자 인식** 기능 — 없으면 채팅방 목록을 읽지 못합니다
  설치: `Windows 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션 → 광학 문자 인식`

### 실행

1. PC 카카오톡을 켜고 **채팅 목록이 보이게** 창을 띄웁니다. 최소화되어 있거나 트레이로 닫혀 있으면 안 됩니다.
2. `카카오톡봇.cmd`를 더블클릭합니다.
3. **시작 화면**이 뜨면서 순서대로 점검합니다.

```
[정상] 운영체제 확인           Windows 11 / PowerShell 5.1
[정상] 카카오톡 실행 확인       카카오톡 1개를 찾았습니다.
[정상] 카카오톡 창 선택         카카오톡 #20724 / 지금 일반채팅 탭
[정상] 한국어 문자 인식 확인     사용 가능
[정상] 최신 배포 확인           최신 버전입니다.
```

- 다섯 줄이 모두 `[정상]`이어야 `시작하기` 버튼이 나옵니다.
- 카카오톡을 **여러 개 켜 두셨다면** 어느 창을 쓸지 고르는 창이 뜹니다.
- 새 버전이 있으면 **업데이트해야 사용할 수 있습니다.**

처음 실행하면 **가이드 투어**가 뜹니다. 오른쪽 위 `?` 버튼으로 언제든 다시 볼 수 있습니다.

> **한 번에 하나만 실행됩니다.** 두 개를 켜면 설정이 서로 덮어써지고, 같은 카카오톡을 동시에 조작해 엉뚱한 방에 보내질 수 있어 막아 두었습니다. 두 번째 실행은 기존 창을 앞으로 가져오고 종료됩니다.

## 1단계 · 보낼 내용 쓰기

`1. 보낼 내용` 화면입니다.

**발송 문구** — 여기 적은 그대로 나갑니다. **줄바꿈도 그대로 유지**되며, 여러 줄이어도 **한 개의 메시지**로 전송됩니다.

**첨부 사진·파일** — `파일 추가`로 넣고 `위로`·`아래로`로 순서를 바꿉니다. 문구가 먼저 나가고, 그다음 첨부가 목록 순서대로 하나씩 나갑니다.

입력한 내용은 **자동 저장**됩니다. 따로 저장할 필요 없습니다.

## 2단계 · 받을 채팅방 고르기

`2. 받을 채팅방` 화면입니다.

### 목록 읽어오기

`카카오톡에서 읽기`를 누르면 지금 카카오톡에서 보고 있는 목록을 훑어 방 이름을 가져옵니다.

읽기 전에 **어느 탭인지 확인**하는 창이 뜹니다. 프로그램이 위쪽 탭 글자를 보고 판별한 결과를 함께 보여 주니 그대로 답하시면 됩니다.

> 읽는 동안에는 마우스와 키보드를 사용하지 마세요.

### 일반채팅과 오픈채팅 나누기 — 순서가 중요합니다

카카오톡 `채팅` 목록에는 **오픈채팅방도 함께 들어 있습니다.** 그래서 탭만으로는 방마다 종류를 알 수 없습니다. 이렇게 하면 정확히 나뉩니다.

1. 카카오톡에서 **`오픈채팅` 탭** → `카카오톡에서 읽기` → 이 방들이 **오픈채팅**으로 표시됩니다
2. 카카오톡에서 **`채팅` 탭** → `카카오톡에서 읽기` → 이미 오픈으로 표시된 방은 **그대로 두고** 나머지만 **일반채팅**이 됩니다

반대 순서로 하셔도 됩니다. **오픈채팅 표시가 항상 우선**이라 나중에 오픈채팅 탭을 읽으면 갱신됩니다.

목록 위의 `전체 / 일반채팅 / 오픈채팅` 버튼으로 걸러 볼 수 있습니다.

### 이름 확인·보정 (꼭 해 주세요)

방 이름은 **화면의 글자를 읽어** 가져오기 때문에 가끔 틀립니다. 보낼 방을 체크한 뒤 `이름 확인·보정`을 누르면, 각 방을 열어 **실제 이름으로 자동 교정**합니다.

- 메시지는 보내지 않지만 채팅방이 열리므로 읽음 표시가 될 수 있습니다.
- 안 잡히는 방은 `직접 추가`로 카카오톡에 보이는 이름 그대로 입력하세요.
- `이름 수정`으로 직접 고칠 수도 있습니다.

> `☆`, `♥`, `&`, 괄호 같은 기호는 화면에서 잘 안 읽힙니다. 프로그램이 기호를 빼고 견주므로 `☆자유로운 홍보방☆`이 `자유로운 홍보방`으로 읽혀도 찾아냅니다.

### 그룹으로 묶기

자주 보내는 방들을 묶어 두면 다음부터 한 번에 고를 수 있습니다.

1. 보낼 방들을 체크합니다
2. `새 그룹 만들기` → 이름 입력 (예: 학부모, 홍보방)
3. 다음부터는 그룹을 고르고 `이 그룹 체크`만 누르면 됩니다

`체크한 방 넣기`로 기존 그룹에 추가할 수 있습니다. `그룹 삭제`는 그룹만 지우고 채팅방 목록은 그대로 둡니다.

### 버튼 정리

| 버튼 | 하는 일 |
| --- | --- |
| `보이는 항목 모두 체크` | 지금 필터에 보이는 것만 체크 |
| `체크 모두 해제` | 전체 체크 해제 |
| `체크한 항목 삭제` | 목록에서만 지웁니다. 카카오톡 채팅방은 그대로입니다 |
| `최대 탐색 화면 수` | 목록을 몇 화면까지 훑을지 (기본 30) |

## 3단계 · 보내기

### 발송 방식

- **실제 발송** — 선택한 모든 방에 문구와 첨부를 보냅니다
- **확인 전용** — 방을 하나씩 열어 이름만 확인하고 **전송하지 않습니다**

### 테스트 모드 (꼭 먼저 해 보세요)

여러 방에 보내기 전에 **한 방에만** 똑같이 보내 결과를 확인합니다.

- `목록에서 고르기` — 저장된 목록에서 검색해 고릅니다
- `나와의 채팅` — 기본값으로 되돌립니다. 아무에게도 가지 않습니다
- `테스트 발송` — 실제와 똑같이 보냅니다. 줄바꿈·사진 순서를 미리 볼 수 있습니다
- `방 확인만` — 채팅창을 열어 이름만 확인하고 전송하지 않습니다

### 지금 실행

`발송 시작`(위쪽) 또는 `지금 실행`을 누르면 **확인 창**이 뜹니다.

- 받는 채팅방 목록 (이름 + 종류)
- 보낼 문구 미리보기
- 첨부 개수
- **예상 소요 시간** — `체크한 300개 · 간격 2초 → 예상 소요 약 18분`

`다음부터 이 확인 창 보지 않기`를 고르면 건너뜁니다.

### 방 사이 간격

방 하나와 다음 방 사이에 쉬는 시간입니다. **0초부터** 설정할 수 있습니다.

방 하나를 처리하는 데 약 **1.6초**가 걸립니다. 여기에 간격이 더해집니다.

| 방 수 | 간격 0초 | 간격 2초 | 간격 5초 |
| --- | --- | --- | --- |
| 50개 | 약 1분 20초 | 약 3분 | 약 5분 30초 |
| 300개 | 약 8분 | 약 18분 | 약 33분 |

> 짧은 시간에 몰아 보내는 것은 **카카오톡 이용 제한의 주된 원인**입니다. 간격을 1~2초 두고 아래 묶음 발송을 함께 쓰시길 권합니다.

### 중지와 일시정지

발송 중에는 위쪽 `발송 시작` 자리에 **`중지`** 가 나타납니다. 누르면 고를 수 있습니다.

- **잠깐 멈추기** — 버튼이 `계속하기`로 바뀝니다. 누르면 이어서 진행합니다
- **완전히 중지** — 남은 방은 보내지 않습니다
- **계속 진행** — 그냥 닫습니다

## 반복 발송과 예약

### 예약

`예약 시각`을 정하고 `예약 시작`을 누릅니다. 기본값은 **다음날 0시**입니다.

`달력에서 고르기`를 누르면 달력과 시·분을 고를 수 있고, 아래에 바로 확인됩니다.

```
2026-08-15 (토) 00:00  ·  약 15시간 뒤
```

자주 쓰는 시각 버튼도 있습니다 — `오늘 밤 9시` / `내일 0시` / `내일 아침 9시` / `10분 뒤`

> 예약 시각까지 **이 프로그램과 PC 카카오톡을 모두 켜 두어야** 합니다. 화면 잠금·절전 상태에서는 동작하지 않습니다.

### 반복 발송

한 번 다 보낸 뒤 일정 시간마다 다시 보냅니다.

```
☑ 반복 발송 — 한 번 다 보낸 뒤 일정 시간마다 다시 보내기
   [ 30 ] 분마다 · 최대 [ 5 ] 회
```

**최대 횟수를 `0`으로 두면** `중지`를 누를 때까지 계속 반복합니다.

### 묶음 발송

`설정` 화면에 있습니다. 한 번에 다 보내지 않고 나눠 보냅니다.

```
묶음 발송  [ 50 ] 개 보낸 뒤  [ 10 ] 분 쉬기   (0개면 쉬지 않고 계속)
```

300개를 50개씩 나눠 10분씩 쉬면 총 약 1시간이 걸리지만, 한꺼번에 몰아 보내는 것보다 안전합니다.

## 발송 제한 (방해금지·주말·공휴일)

`설정` 화면의 **발송 제한 및 묶음 발송** 카드입니다.

- **방해금지 시간대** — 예: `21:00` 부터 `08:00` 까지. 자정을 넘는 구간도 됩니다
- **주말(토·일)에는 보내지 않기**
- **공휴일에는** `평소대로` / `보내지 않음` / `간격 늘리기`(배수 지정)

동작 방식:

- `지금 실행`이 제한에 걸리면 이유와 다음 가능 시각을 보여 주고 한 번 더 확인합니다
- **예약 발송이 제한에 걸리면 취소하지 않고 보낼 수 있는 다음 시각으로 미룹니다**
- 발송 도중 방해금지 시간대로 들어가면 남은 방은 보내지 않고 멈춥니다

공휴일은 양력 고정일과 **음력 명절(설날·추석·부처님오신날)**, 그리고 **대체공휴일**까지 계산합니다. `올해 공휴일 보기`로 실제 목록을 확인하세요.

임시공휴일은 자동으로 알 수 없으므로, 필요하면 `config.json`의 `ExtraHolidays`에 `"2026-10-16"` 형식으로 추가하시면 됩니다.

## 설정

### 카카오톡 연결 상태

`지금 확인`을 누르면 지금 상태를 점검합니다.

```
[정상] 카카오톡 연결됨 - 지금 선택된 탭: 일반채팅 탭
[정상] 채팅방 목록을 찾았습니다. (화면 ChatRoomListView)
[정상] 한국어 문자 인식 사용 가능
[안내] 채팅/오픈채팅 탭과 검색 아이콘은 자동으로 찾습니다. 따로 설정할 것이 없습니다.
```

`카카오톡 창 앞으로 가져오기`로 카카오톡을 띄울 수 있습니다.

> **좌표를 맞추는 설정은 없습니다.** 카카오톡 창의 내부 구조를 실행할 때마다 읽어 스스로 찾습니다. 창 크기나 화면 배율을 바꿔도 다시 설정할 필요가 없습니다.

### 업데이트

- `시작할 때 자동 확인` — 실행 직후 조용히 확인
- `새 버전이 있으면 물어보고 바로 받기` — 확인 한 번으로 내려받기·설치·재시작까지
- `로그 파일 모두 지우기` — 실행 기록 파일을 모두 삭제 (되돌릴 수 없습니다)

새 버전이 있으면 **업데이트해야 사용할 수 있습니다.** 기존 파일은 `backup\날짜-시각\` 폴더에 보관되고 설정은 유지됩니다.

### 도움말 및 관리

`가이드 다시 보기` / `프로그램 폴더 열기` / `로그 폴더 열기` / `설정 초기화`

## 잘못 보내지 않도록 하는 안전장치

이 프로그램은 **틀리면 보내지 않는 쪽**으로 만들어졌습니다.

1. **창 제목 확인** — 방을 연 뒤 채팅창 제목이 정확히 일치하지 않으면 닫고 건너뜁니다
2. **입력 내용 확인** — 입력칸에 넣은 글을 다시 읽어 문구와 다르면 **보내지 않습니다**
3. **전송 성공 확인** — 카카오톡은 전송에 성공하면 입력칸을 비웁니다. 이걸로 성공을 판단하며, 실패하면 입력칸을 비우고 실패로 기록합니다
4. **중복 전송 방지** — 이미 보내진 뒤에는 입력칸이 비어 있어 다음 시도가 아무 일도 하지 않습니다
5. **한 번에 최대 500개**

## 자주 묻는 것

**발송 중에 컴퓨터를 써도 되나요?**

권하지 않습니다. 방을 열고 닫고 목록을 넘기는 일은 백그라운드로 처리되지만, **전송하는 순간에는 채팅창이 잠깐 앞으로 나와야 합니다**(방당 약 1초). 카카오톡이 프로그램으로 넣은 글자를 사용자 입력으로 인정하지 않아 실제 키보드 입력이 필요하기 때문입니다. 그때 타자를 치시면 그 글자가 채팅창으로 들어갈 수 있습니다.

자리를 비우는 시간대에 **예약**해 두시는 쪽을 권합니다.

**마우스는 움직이나요?**

아니요. 마우스 커서는 건드리지 않습니다.

**카카오톡을 여러 개 켜 두었는데요?**

시작 화면에서 어느 창을 쓸지 고릅니다. 고른 창에만 보냅니다.

**여러 줄 문구를 보내면 줄마다 따로 가나요?**

아니요. 줄바꿈은 Shift+Enter로 처리해 **한 개의 메시지**로 보냅니다.

**동명 채팅방이 있으면요?**

구분할 수 없습니다. 카카오톡에서 방 이름을 서로 다르게 바꾼 뒤 사용하세요.

## 다른 사람에게 넘기거나, 처음부터 다시 하고 싶을 때

이 프로그램은 **설정과 실행 기록을 프로그램 폴더 안에 보관합니다.**

```
config.json   받을 채팅방 목록, 문구, 예약 설정
logs/         지난 실행 기록 (보낸 방 이름이 들어 있습니다)
backup/       업데이트 전 프로그램 파일 (개인 정보 없음)
```

새로 내려받아도 **같은 폴더에 풀면 config.json 과 logs 가 그대로 남습니다.** 설정을 지키려고 일부러 그렇게 만들었습니다.

그래서 **폴더째로 다른 사람에게 주면 내 채팅방 목록과 실행 기록도 같이 갑니다.**

`설정` 화면 맨 아래 **`처음 상태로 되돌리기`** 를 누르면 config.json 과 logs 를 모두 지우고 처음 받은 상태가 됩니다. 폴더를 넘기기 전에 이 버튼을 눌러 주세요.

깨끗한 상태로 새로 쓰고 싶을 때도 같은 버튼입니다.

## 사진·파일 첨부

오랫동안 첨부가 안 갔던 이유를 찾았습니다.

카카오톡은 사진을 붙여넣으면 채팅창에 바로 붙이지 않고 **`클립보드 이미지 전송` 이라는 미리보기 창을 따로 띄웁니다.** 그 창에서 `전송`을 눌러야 실제로 갑니다. 예전 코드는 이 창의 존재를 몰라서 채팅창만 보고 "안 붙었다"고 판단했고, 그래서 `전송`을 누르지 않았습니다.

지금은 이렇게 동작합니다.

```
사진   붙여넣기 → 미리보기 창 확인 → 그 창의 [전송] 누름 → 창이 닫히면 성공
문서   [파일] 아이콘 → 파일 선택창에 경로 입력 → [열기] → 전송
```

한쪽이 막히면 다른 쪽으로 자동으로 넘어갑니다.

**보냈는지 확인하는 방법도 바꿨습니다.** 예전에는 입력칸이 비었는지를 봤는데, 첨부는 입력칸이 처음부터 비어 있어 항상 성공으로 보였습니다. 지금은 **전송 버튼이 노랗게 켜졌다가 꺼지는 것**과 **미리보기 창이 닫히는 것**으로 확인합니다.

**확인되지 않으면 보내지 않고 붙인 것을 치웁니다.** 잘못 보내는 것보다 안 보내는 것이 낫습니다.

### 먼저 시험해 보세요

`1. 보낼 내용` 화면의 **`첨부 시험`** 버튼을 누르면 첨부가 붙는지만 확인하고 **보내지 않습니다.** 실제 발송 전에 이 환경에서 첨부가 되는지 미리 알 수 있습니다.

## 오픈채팅에서 전송이 안 되던 문제

방은 열리는데 글이 안 나가던 이유를 실제로 재서 찾았습니다.

```
창 제목과 입력칸이 준비되는 시간      약 0.4초
대화 내용을 다 불러오는 시간          0.9초 ~ 12초  (방마다 다름)
```

**대화를 불러오는 중에는 Enter 를 눌러도 아무 일이 없습니다.** 예전 코드는 0.4초에 보내 버려서, 12초짜리 방은 계속 실패했습니다.

지금은 **화면이 멈출 때까지 기다린 뒤** 보냅니다. 그리고 **보낸 뒤 확인해서 안 갔으면 다시 보냅니다.**

다시 보내기 전에 **입력칸을 반드시 확인합니다.** 비어 있으면 이미 간 것이므로 다시 보내지 않습니다. 같은 글이 두 번 가는 일을 막습니다.

`설정 → 대화 로딩 대기` 에서 기다리는 시간을 정할 수 있습니다. 기본 4초이고, 오픈채팅이 많으면 10~15초로 올려 주세요.

### 이름이 잘린 방도 찾습니다

카카오톡 목록은 이름이 길면 뒤를 `…` 로 줄여 보여 줍니다. 예전에는 이 잘린 이름이 창 제목과 달라서 그 방들이 전부 건너뛰어졌습니다.

지금은 앞부분이 같으면 같은 방으로 봅니다. 다만 **앞부분이 같은 방이 둘 이상이면 보내지 않습니다.** 엉뚱한 방에 보내는 것보다 안 보내는 것이 낫습니다.

### 방 이름 정리

읽어 온 이름에서 아래를 걷어냅니다.

```
안 읽은 개수 뱃지    0 홍보방      →  홍보방
잘림 표시            긴 방이름…    →  긴 방이름
인식 찌꺼기          폰고 ′,       →  폰고
이모티콘·그림문자
```

진짜 이름이 숫자로 시작하는 방(`5K 디자인`, `95 비와이`)은 **그대로 둡니다.**

**이미 읽어 둔 목록에는 옛 이름이 남아 있습니다.** `2. 받을 채팅방 → 카카오톡에서 읽기` 를 한 번 다시 눌러 주세요.

### 목록을 종류로 나누지 않습니다

오픈채팅과 일반채팅을 따로 묶지 않고 **이름 순서 한 줄로** 보여 줍니다. 종류로 골라 보고 싶을 때만 위쪽 `개인` `그룹` `오픈채팅` 버튼을 쓰면 됩니다.

## 어떤 컴퓨터는 되고 어떤 컴퓨터는 안 되던 이유

예전 방식은 **두 가지에 기대고 있었습니다.** 둘 다 그 컴퓨터가 그때 어떤 상태냐에 따라 달라집니다.

```
1. 클립보드    다른 프로그램이 잡고 있으면 못 씁니다
2. 창 활성화   윈도우가 막으면 창을 앞으로 못 가져옵니다
```

실제로 이 PC 에서 재봤더니 **클립보드는 12번 시도해도 전부 실패**했습니다. 다른 프로그램이 계속 붙잡고 있었습니다. 그리고 창 활성화는 원격 데스크톱으로 접속했거나, 다른 창을 쓰고 있거나, 화면이 잠기면 막힙니다.

예전 코드는 창을 앞으로 못 가져오면 **아무것도 안 하고 그냥 포기**했습니다. 그래서 되는 컴퓨터와 안 되는 컴퓨터가 갈렸습니다.

### 지금은 둘 다 필요 없습니다

확인해 보니 카카오톡은 **창 메시지로 넣은 글도 사람이 친 것으로 인정합니다.**

```
창 메시지로 글 넣기      [안녕하세요 테스트]    전송버튼 켜짐
창 메시지로 백스페이스   먹음
창 메시지로 방향키       먹음
창 메시지로 여러 줄 넣기 3줄 그대로, 전송버튼 켜짐
```

**전부 창을 앞으로 가져오지 않은 상태에서 된 것입니다.**

그래서 이제 이 순서로 합니다.

```
1순위  창 메시지로 끼워 넣기   클립보드 X, 창 활성화 X   ← 거의 항상 됩니다
2순위  한 글자씩 넣기          클립보드 X, 창 활성화 X
3순위  클립보드 붙여넣기
4순위  창을 앞으로 가져와 키보드
```

앞의 것이 실패해야 다음으로 넘어갑니다. **어느 하나가 막혀도 발송이 멈추지 않습니다.**

덤으로, 이제 **마우스와 키보드를 쓰면서도 발송이 됩니다.** 창이 앞으로 튀어나오지 않습니다.

## 300개 방을 10분 안에 보내려면

한 방에 드는 시간은 이렇습니다.

```
방 열기            약 0.3초
제목·입력칸 확인   약 0.4초
대화 로딩 대기     0.4초 ~ 설정한 시간
글 넣고 보내기     약 0.5초
──────────────────────────────
합계               약 1.6초 ~
```

여기에 **방과 방 사이 간격**이 더해집니다. `설정 → 발송 간격` 이 **기본 8초**입니다.

```
간격 8초  →  300 × (1.6 + 8) = 약 48분
간격 2초  →  300 × (1.6 + 2) = 약 18분
간격 1초  →  300 × (1.6 + 1) = 약 13분
간격 0초  →  300 × 1.6       = 약 8분
```

**300개를 10분 안에 보내시려면 간격을 0~1초로 두셔야 합니다.** 다만 간격을 너무 줄이면 카카오톡이 이용을 제한할 수 있습니다. 처음에는 2초 정도로 해 보시고 늘리거나 줄이시는 것을 권합니다.

`대화 로딩 대기` 도 시간에 그대로 더해집니다. 오픈채팅이 많으면 늘려야 하지만, 늘린 만큼 전체가 느려집니다.

## 설정은 한 곳에만 있습니다

예전에는 `방 사이 간격`과 `반복`이 **보내기 화면**에 있고, 나머지가 **설정 화면**에 있어서 어디서 바꿔야 하는지 헷갈렸습니다.

이제 **모든 설정은 `설정` 화면 한 곳**에 있습니다. `설정 → 발송 진행 방식` 에 이렇게 모았습니다.

```
방 사이 간격      0~300초
방 열림 대기      3~60초
대화 로딩 대기    0~30초
처음 보내기 전에 방 미리 열기
반복 발송         몇 분마다 · 최대 몇 회
```

`보내기` 화면에는 **지금 어떻게 설정돼 있는지 요약만** 보입니다. 바꾸려면 그 옆 `설정에서 바꾸기` 를 누르면 됩니다.

## 처음 쓰실 때 — 방 미리 열기

카카오톡을 막 켰거나 이 프로그램을 처음 쓰시면, 채팅방마다 대화를 **처음부터 새로 불러옵니다.** 방에 따라 12초까지 걸리고, **다 불러오기 전에는 전송이 되지 않습니다.**

그래서 **처음 보낼 때는 대상 방을 먼저 한 번씩 열어 둡니다.** 기본으로 켜져 있고, 처음 한 번만 합니다.

```
방 미리 열기: 300개를 한 번씩 열어 대화가 다 불러와지는지 봅니다.
보내지 않습니다. 처음 한 번만 하면 되고, 이후 발송이 훨씬 안정적입니다.
...
방 미리 열기 끝: 확인 297개 / 열지 못함 2개 / 목록에서 못 찾음 1개
```

한 번 열어 둔 방은 카카오톡이 기억하고 있어서 다음부터 금방 열립니다. 언제든 `설정 → 지금 미리 열기` 로 다시 하실 수 있습니다.

**메시지는 보내지 않습니다.** 방을 열어 확인만 합니다.

## 프로그램으로 실행하기 (다른 컴퓨터에서 쓰기 좋습니다)

배포 파일 안에 **`카카오 발송기.exe`** 가 들어 있습니다. **두 번 누르면 바로 실행됩니다.**

파워셸이나 실행 정책을 몰라도 되고, `.cmd` 를 거치지 않아도 됩니다. 다른 컴퓨터에 폴더째 복사해서 바로 쓰시면 됩니다.

```
카카오 발송기.exe        ← 이것만 두 번 누르면 됩니다
KakaoRoomScheduler.ps1   같은 프로그램의 스크립트 판 (예전 방식)
카카오톡봇.cmd            스크립트 판 실행기
```

**설정과 기록은 프로그램이 있는 폴더 안에 만들어집니다.** 폴더째 옮기면 설정도 같이 갑니다.

업데이트도 그대로 됩니다. 실행 중인 프로그램 파일은 자기 자신을 덮어쓸 수 없어서, 새 파일을 옆에 받아 두었다가 **다시 시작할 때 바꿔치기**합니다.

스크립트 판(`.ps1`)도 그대로 들어 있으니 원래 쓰시던 방식도 계속 됩니다.

## 채팅방 목록이 저절로 정리됩니다

예전에 저장된 이름에는 안 읽은 개수 뱃지나 잘림 표시가 그대로 남아 있어서, 같은 방이 두 번 보이곤 했습니다.

```
*자유로운 홍보방*
0 *자유로운 홍보방*    ← 같은 방인데 뱃지가 붙어 따로 저장됨
0 [ZZAN] 기TTME/RHY…
```

이제 **프로그램을 켤 때 한 번 정리하고 같은 방은 합칩니다.** 종류와 그룹 정보도 함께 옮겨집니다.

실제로 정리한 결과입니다.

```
채팅방 목록을 정리했습니다: 이름 다듬음 32개 · 같은 방 합침 16개
192개  →  179개
```

## 실패하면 까닭을 남깁니다

예전에는 발송이 실패해도 **채팅창이 켜졌다 바로 꺼지기만** 하고 왜 그런지 알 수 없었습니다.

이제 무엇 때문인지 `실행 기록` 에 남습니다.

```
실패: '우리반 공지방' — 글을 넣는 중 문제가 생겼습니다: ...
실패: '우리반 공지방' — 입력칸에 문구를 넣지 못했습니다.
실패: '우리반 공지방' — Enter 를 눌러도 전송되지 않았습니다. (대화를 아직 불러오는 중일 수 있습니다)
```

## 보내지도 않고 완료라고 하던 문제

**가장 나쁜 종류의 버그였습니다.** 글이 실제로 가지 않았는데 `작업 완료` 라고 알렸습니다.

원인은 두 가지가 겹친 것입니다.

**1. 넣는 방법을 잘못 골랐습니다.** 창 메시지로 입력칸에 글을 넣으면 **전송 버튼이 노랗게 켜집니다.** 그래서 카카오톡이 받아들인 줄 알았습니다. 그런데 Enter 를 누르면 **카카오톡이 그 글을 그냥 지워 버리고 보내지 않습니다.**

**2. 성공 판정이 틀렸습니다.** "입력칸이 비었으면 보낸 것"으로 봤습니다. 카카오톡이 글을 지워도 입력칸은 비므로, **지워진 것을 보낸 것으로 착각**했습니다.

### 고친 방법

**넣는 순서를 되돌렸습니다.** 사람이 직접 친 것과 같은 방법을 먼저 씁니다.

```
1순위  실제 붙여넣기   창을 앞으로 가져와 Ctrl+V
2순위  실제 키보드     창을 앞으로 가져와 직접 입력
3순위  창 붙여넣기     창 메시지로 붙여넣기
4순위  창 메시지       마지막 수단
```

**진짜 갔는지 대화창을 보고 확인합니다.** 입력칸이 비는 것만으로는 판단하지 않습니다. 대화창 아래쪽에 **새 말풍선이 생겼는지** 봅니다.

```
가만히 있을 때 지문 같은가   True
안 보낸 상태에서 "갔는가"    False   ← 거짓 성공 없음
입력칸에 글자만 넣었을 때    False   ← 속지 않음
```

한 방법으로 안 가면 다음 방법으로 다시 넣어 봅니다. **끝까지 확인되지 않으면 실패로 알리고, 왜 그런지 기록에 남깁니다.**

```
실패: '방이름' — '창 메시지' 로 넣은 글을 카카오톡이 지웠습니다. 보내지지 않았습니다.
```

## 화면을 새로 만들었습니다

밝고 단순하게 다시 그렸습니다.

```
검은 사이드바      →  흰 바탕에 얇은 선 하나
카드 테두리        →  없앰. 흰 면과 여백만으로 구역을 나눔
단추 테두리        →  없앰. 옅은 회색 면으로 표시
노란 단추 13개     →  4개 (실제로 보내는 것만)
```

**노란색은 실제로 보내는 단추에만 씁니다.** `발송 시작`, `지금 실행`, `테스트 발송`, `보내기`. 나머지 중요한 단추는 짙은 회색으로, 보조 단추는 옅은 회색으로 구분됩니다. 어디를 눌러야 실제로 보내지는지 한눈에 보입니다.

첨부 목록에는 긴 경로 대신 **파일 이름만** 보입니다.

화면 요소가 서로 겹치지 않는지 **검사로 확인**합니다. 눈으로 놓치던 것을 잡아 줍니다.

## 방만 열고 아무것도 안 보내던 이유

**`확인 전용` 모드로 돌고 있었습니다.**

이 모드는 방을 하나씩 열어 이름만 확인하고 **아무것도 보내지 않습니다.** 연습용입니다. 그런데 두 가지가 겹쳐 알아채기 어려웠습니다.

```
새로 설치하면 기본값이 확인 전용이었습니다
끝나면 '작업 완료' 라고 나와 보낸 줄 알기 쉬웠습니다
```

증상이 정확히 이렇습니다. **채팅방은 열리는데 입력칸에 아무것도 안 들어가고, 그래도 완료라고 나옵니다.**

### 고쳤습니다

**기본값을 `실제 발송` 으로 바꿨습니다.** 새로 설치하면 바로 보낼 수 있습니다.

**확인 전용일 때는 완료라고 하지 않습니다.**

```
확인만 함: '방이름' — 방은 열렸습니다. 아무것도 보내지 않았습니다.
확인 전용으로 끝났습니다: 방 12개를 열어 보았고, 실제로 보낸 메시지는 없습니다.
실제로 보내시려면 [3. 보내기] 화면에서 [실제 발송] 을 고르세요.
```

**화면 맨 위에 항상 보입니다.** 확인 전용이면 붉은 글씨로 `확인 전용 — 보내지 않습니다` 가 뜨고, 시작 단추 이름도 `확인 시작` 으로 바뀝니다.

## 복사해 둔 내용이 대신 나가던 문제

글을 넣을 때 **클립보드에 우리 문구를 넣고 Ctrl+V** 를 누릅니다. 그런데 클립보드에 넣는 것이 **성공한 것처럼 보여도 실제로는 반영되지 않는 경우**가 있습니다. 다른 프로그램이 클립보드를 잡고 있을 때 그렇습니다.

그러면 **사용자가 복사해 두었던 엉뚱한 내용이 그대로 붙어 나갑니다.**

이제 **누르기 직전에 클립보드를 다시 읽어 확인**합니다.

```
넣고 확인          True    → 붙여넣기 진행
다른 내용일 때     False   → 붙여넣기 건너뛰고 직접 입력으로
```

우리 문구가 아니면 **붙여넣지 않고 다른 방법으로 넘어갑니다.**

### 복사해 두신 것도 지켜 드립니다

발송을 시작할 때 클립보드에 있던 것을 챙겨 두었다가 **끝나면 되돌려 놓습니다.** 발송했다고 복사해 둔 것이 날아가지 않습니다.

### 기록에 문구 길이가 남습니다

```
작업 시작: 방 3개 / 모드=실제 발송 / 간격 0초
보낼 문구 491자 / 첨부 1개
```

문구가 `0자` 로 나오면 보낼 내용이 비어 있는 것입니다.

## 어떤 컴퓨터에서 아예 전송이 안 되던 이유

**입력칸이 키보드 입력을 받는 상태가 아니었습니다.**

우리가 방금 연 방은 대개 입력칸이 활성화되어 있습니다. 그런데 **이미 열어 두셨던 방**은 포커스가 대화 목록 쪽에 가 있거나, **아예 아무 칸도 포커스를 받지 않은 상태**일 수 있습니다.

실제로 재 봤습니다.

```
지금 키보드 입력을 받는 칸 : 0        ← 아무 데도 없습니다. Enter 가 갈 곳이 없습니다
포커스를 맞춘 뒤           : 입력칸  (341ms)
```

이제 **글을 넣기 전과 Enter 를 누르기 전에 입력칸에 확실히 포커스를 맞춥니다.** 세 번까지 확인하고, 안 되면 입력칸을 눌러 줍니다.

## 목록 읽기 안내를 단순하게

예전에는 읽을 때마다 `[예] 오픈채팅 / [아니오] 일반채팅` 을 고르게 했습니다. 매번 고르기도 번거롭고 잘못 고르기도 쉬웠습니다.

이제 **카카오톡 위쪽 탭을 보고 알아서 정합니다.** 확인 창은 이렇게만 나옵니다.

```
지금 카카오톡에서 보고 있는 목록을 읽습니다.

· 읽을 종류: 오픈채팅 으로 저장합니다
· 카카오톡 화면: ChatRoomListView

카카오톡에서 오픈채팅을 따로 보고 계시면, 그 설정을 끄면
[채팅] 목록 하나에서 전부 읽을 수 있어 편합니다.
  카카오톡 설정 → 채팅 → 오픈채팅 분리해서 보기 → 끄기

[확인] 읽기 시작    [취소] 그만두기
```

읽는 중에 잘못 눌렀으면 **[취소]** 로 그만둘 수 있습니다.

## 엉뚱한 방이 열리던 문제

기록을 보니 이런 일이 벌어지고 있었습니다.

```
'마케팅 자유 홍보.-'  →  실제로 열린 창: '자유홍보 광고/마케팅 공유방'
'자유홍보 광고/마'    →  실제로 열린 창: '무한,광고,홍보,유통,제조,소통,'
'스마트스토어 불로'   →  실제로 열린 창: '스마트스토어 블로그 인스타그램 홍보방...'
```

**저장된 이름으로 목록을 뒤지는 방식 자체가 한계였습니다.** 목록에 보이는 이름은 길면 잘리고, 화면 글자 인식도 가끔 틀립니다(`블` → `불`). 그러니 비슷한 다른 줄이 걸려 엉뚱한 방이 열렸습니다.

### 창 제목을 기준으로 삼습니다

**창을 열고 나면 제목은 정확한 글자로 읽을 수 있습니다.** 이제 그것을 기준으로 합니다.

```
1. 목록에서 비슷한 줄을 눌러 방을 엽니다
2. 열린 창의 제목을 읽습니다          ← 이것이 정답입니다
3. 보낼 목록 중 어느 방인지 다시 정합니다
4. 맞으면 그 방으로 보냅니다
5. 저장된 이름을 실제 제목으로 바꿔 둡니다   ← 다음부터는 헤매지 않습니다
```

**보낼 목록에 없는 방이 열리면 닫고 지나갑니다.** 그 줄은 다시 고르지 않습니다.

**두 방이 비슷하게 걸리면 보내지 않습니다.** 어느 쪽인지 모르는 채로 보내는 것보다 안 보내는 편이 낫습니다.

### 확인한 것

```
통과  '자유홍보 광고/마케팅 공유방'          → '자유홍보 광고/마'    (잘린 이름)
통과  '스마트스토어 블로그 인스타그램...'    → '스마트스토어 불로'   (글자 인식 오류)
통과  '※자유 홍보 방 ※ 와서 홍보 하세요!'   → '※자유 홍보 방 ※'    (기호 포함)
통과  '무한,광고,홍보,유통,제조,소통,'       → 없음                 (목록에 없는 방)
통과  비슷한 방이 둘일 때                     → 없음                 (헷갈리면 안 보냄)
```

이름 다듬기도 넓혔습니다.

```
0※자유 홍보 방 ※   →  ※자유 홍보 방 ※      기호 앞에 붙은 뱃지
마케팅 자유 홍보.-  →  마케팅 자유 홍보      줄 끝 찌꺼기
```

## 문제가 생겼을 때

| 증상 | 확인할 것 |
| --- | --- |
| 카카오톡을 찾지 못함 | PC 카카오톡 실행 여부. 트레이(시계 옆)로 닫혀 있으면 아이콘을 눌러 창을 열어 주세요 |
| 목록을 읽었는데 0개 | 카카오톡에 채팅 목록이 보이는 상태인지, 한국어 문자 인식이 설치됐는지 확인 |
| 방을 못 찾고 건너뜀 | 체크한 뒤 `이름 확인·보정` 실행. 그래도 안 되면 `직접 추가` |
| 오픈채팅방이 안 읽힘 | 카카오톡에서 `오픈채팅` 탭으로 바꾼 뒤 다시 읽기 |
| 전송이 안 됨 | `실행 기록`에서 `전송 방식:` 또는 `실패:` 줄을 확인 |
| 이미 실행 중이라고 나옴 | 정상입니다. 기존 창을 쓰세요. 창이 안 보이면 작업 관리자에서 `powershell` 종료 |
| 한글이 깨져 보임 | 파일이 UTF-8 BOM으로 저장됐는지 확인 |

기록은 `logs\날짜.log` 파일에도 남습니다. 문제를 알려 주실 때 이 파일이 도움이 됩니다.

## 관리자용 — 배포하기

어디서든, 휴대폰 브라우저에서도 수정하고 배포할 수 있습니다.

**GitHub 웹에서**: 저장소에서 파일 수정 → `Actions` 탭 → `release` → `Run workflow` → 버전 입력

**이 PC에서**: `.\Publish-Release.ps1 -Version 4.9.1 -Notes "변경 내용"`

**태그로**: `git tag v4.9.1 && git push origin v4.9.1`

> 스크립트는 **UTF-8 BOM**으로 저장해야 합니다. PowerShell 5.1은 BOM이 없으면 한글을 깨뜨립니다. 배포 워크플로가 자동으로 BOM을 넣어 주지만, 직접 편집하실 때는 주의하세요.

### 개발자 명령

```
카카오톡봇.cmd 대신 아래처럼 실행하면 화면 없이 점검만 합니다.

powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\KakaoRoomScheduler.ps1 -SelfTest
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\KakaoRoomScheduler.ps1 -ScanTest -MaskNames
```

`-SelfTest`는 설정 구조, 이름 필터, 행 분리, 공휴일 계산, 문구 변환 등을 점검합니다.
`-ScanTest`는 창을 띄우지 않고 채팅방 목록 읽기만 실행합니다.

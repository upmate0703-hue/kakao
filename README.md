# 카카오 발송기 (KakaoRoomScheduler)

Windows PC 카카오톡의 채팅방 목록을 읽어 발송 대상을 고르고, 같은 문구와 사진·파일을 한 번에 또는 예약한 시각에 보내는 보조 프로그램입니다.

카카오 계정·비밀번호·인증정보는 사용하지 않고 저장하지도 않습니다. 화면에 이미 로그인된 PC 카카오톡을 사람처럼 클릭해서 동작합니다.

---

## 빠른 시작

1. PC 카카오톡에 로그인하고 메인 채팅 목록을 화면에 띄웁니다.
2. `Start-KakaoRoomScheduler.cmd`를 더블클릭합니다.
3. 처음 실행하면 **가이드 투어**가 자동으로 뜹니다. 7단계를 따라가면 준비가 끝납니다.
4. 가이드는 언제든 `설정 → 가이드 다시 보기`에서 다시 볼 수 있습니다.

---

## 화면 구성

| 화면 | 하는 일 |
| --- | --- |
| **발송 준비** | 보낼 문구 작성, 사진·파일 첨부와 순서 조정 |
| **채팅방 선택** | 카카오톡에서 방 목록 읽기, 대상 체크, 이름 수정·직접 추가 |
| **실행 · 예약** | 발송 방식 선택, 테스트 발송, 지금 실행 / 예약 실행 |
| **설정** | 화면 위치 보정, 업데이트 확인, 가이드 다시 보기, 폴더 열기 |
| **실행 기록** | 성공·건너뜀·오류 기록 확인 |

---

## 1단계 · 화면 위치 보정 (처음 한 번)

이 프로그램은 카카오톡 창의 세 위치를 좌표 비율로 기억해 두고 클릭합니다.

`설정` 화면에서 아래 세 버튼을 차례로 누르고, 안내에 따라 해당 위치에 마우스를 올린 뒤 **F8**을 누르세요.

- `① 채팅탭` — 카카오톡 왼쪽의 말풍선 모양 채팅 탭
- `② 검색창` — 채팅 목록 상단의 방 검색 입력칸
- `③ 첫 검색결과` — 검색어를 입력했을 때 나오는 첫 번째 방 이름

> 카카오톡 창 크기나 Windows 화면 배율을 바꾸면 다시 보정해야 합니다.

---

## 2단계 · 채팅방 목록 읽기

`채팅방 선택 → 카카오톡에서 읽기`를 누르면 Windows 접근성 정보(UI Automation)로 채팅 목록을 읽고, 목록을 아래로 넘기며 방 이름 후보를 모읍니다.

- 읽는 동안에는 **마우스와 키보드를 사용하지 마세요.**
- 카카오톡 버전에 따라 방 이름 대신 최근 메시지 미리보기가 섞여 들어올 수 있습니다. 체크하기 전에 확인하세요.
- 틀린 이름은 `이름 수정`으로 고치고, 자동으로 안 잡히는 방은 `직접 추가`로 정확히 입력합니다.
- **동명 채팅방은 구분되지 않습니다.** 카카오톡에서 방 이름을 서로 다르게 바꾼 뒤 사용하세요.
- `최대 탐색 페이지`로 목록을 얼마나 깊게 넘길지 정할 수 있습니다(기본 20).

---

## 3단계 · 테스트 모드로 먼저 확인

실제 발송 전에 반드시 테스트하세요. `실행 · 예약` 화면에 두 가지 안전장치가 있습니다.

**테스트 발송** — 지정한 **한 방에만** 실제와 똑같이 문구와 첨부를 보냅니다.
기본값은 `나와의 채팅`이라 아무에게도 전달되지 않으면서, 줄바꿈·사진 순서를 눈으로 확인할 수 있습니다.

**방 확인만** — 채팅창을 열어 제목이 정확히 일치하는지만 확인하고 전송하지 않습니다.

또한 발송 방식에서 `확인 전용`을 고르면, 선택한 **모든** 방을 하나씩 열어 이름만 검사하고 전송하지 않습니다. 전체 목록이 맞는지 점검할 때 쓰세요.

---

## 4단계 · 실행과 예약

- `지금 실행` — 바로 발송합니다.
- `예약 시작` — 지정한 시각에 자동 발송합니다.
- `예약 취소` — 대기 중인 예약을 해제합니다.

예약 실행 조건:

- 예약 시각까지 이 프로그램과 PC 카카오톡을 모두 켜 두어야 합니다.
- Windows가 잠금·절전·화면 보호 상태이면 화면 자동화가 동작하지 않습니다.
- 실행 중에는 마우스와 키보드를 사용하지 마세요.
- 카카오톡 창 크기와 화면 배율을 보정했을 때와 같게 유지하세요.

안전장치:

- 방 사이 간격 최소 5초, 한 작업 최대 50개 방
- 검색해서 열린 채팅창 제목이 정확히 일치할 때만 전송 (`방이름` 또는 `방이름 (인원수)`)
- 첨부 파일이 하나라도 없으면 실제 실행 전에 중단
- 실제 발송 직전 대상 개수와 첨부 개수를 보여 주고 한 번 더 확인

---

## 자동 저장

입력을 멈추면 약 0.8초 뒤 자동 저장되고, 창을 닫을 때 한 번 더 저장됩니다.

저장 항목: 선택한 방과 읽어온 방 후보, 문구, 첨부 경로와 순서, 예약 시각, 방 간격, 발송 방식, 탐색 페이지 수, 테스트 방 이름, 화면 보정 위치, 가이드 표시 여부.

저장 위치는 프로그램 폴더의 `config.json`입니다. 이 파일은 이 PC 안에만 있으며 저장소에 올라가지 않습니다.

---

## 업데이트

`설정 → 업데이트`에서 GitHub 저장소의 최신 배포본을 확인합니다.

- `시작할 때 자동 확인`이 켜져 있으면 실행 직후 조용히 확인하고, 새 버전이 있으면 왼쪽 아래에 노란 알림이 뜹니다.
- `지금 업데이트`를 누르면 새 버전을 내려받아 적용하고 프로그램을 다시 시작합니다.
- 기존 파일은 `backup\날짜-시각\` 폴더에 보관되며, `config.json`과 `logs`는 그대로 유지됩니다.
- `저장소 열기`로 변경 내용을 직접 확인할 수도 있습니다.

---

## 배포하기 (관리자용)

어디서든 — 심지어 휴대폰 브라우저에서도 — 수정하고 배포할 수 있습니다.

### 방법 A · GitHub 웹에서 (설치 불필요)

1. GitHub 저장소에서 파일을 열고 연필 아이콘으로 수정한 뒤 커밋합니다.
2. `Actions` 탭 → `release` 워크플로 → `Run workflow`를 누릅니다.
3. 버전(예: `3.1.0`)과 변경 내용을 입력하고 실행합니다.

워크플로가 스크립트에 버전을 기록하고, 커밋·태그·압축·릴리스 등록까지 자동으로 처리합니다.

### 방법 B · 이 PC에서 명령 한 줄

```powershell
.\Publish-Release.ps1 -Version 3.1.0 -Notes "채팅방 읽기 정확도 개선"
```

자체 점검 → 커밋·푸시 → 워크플로 실행까지 한 번에 진행합니다. `git`과 `gh`(GitHub CLI 로그인 완료)가 필요합니다.

### 방법 C · 태그 푸시

```bash
git tag v3.1.0 && git push origin v3.1.0
```

어떤 방법을 쓰든 결과는 같습니다. 사용자는 프로그램의 `업데이트 확인`에서 새 버전을 받게 됩니다.

> 스크립트는 **UTF-8 BOM**으로 저장해야 합니다. PowerShell 5.1은 BOM이 없으면 한글을 깨뜨립니다. GitHub 웹 편집기는 기존 인코딩을 유지하므로 그대로 수정해도 안전합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `Start-KakaoRoomScheduler.cmd` | 실행 파일 (더블클릭) |
| `KakaoRoomScheduler.ps1` | 프로그램 본체 |
| `Publish-Release.ps1` | 이 PC에서 배포를 실행하는 스크립트 |
| `.github/workflows/release.yml` | GitHub 자동 배포 워크플로 |
| `config.json` | 자동 저장 설정 (저장소에 올라가지 않음) |
| `logs\YYYY-MM-DD.log` | 날짜별 실행 기록 |
| `backup\` | 업데이트 전 파일 백업 |

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 카카오톡 창을 찾지 못함 | PC 카카오톡이 실행 중이고 최소화되지 않았는지 확인 |
| 방을 못 열고 계속 건너뜀 | 방 이름이 카카오톡 표시와 정확히 같은지, 세 위치 보정이 최신인지 확인 |
| 목록에 이상한 문구가 섞임 | 카카오톡 버전 차이입니다. `이름 수정`·`직접 추가`로 정리하세요 |
| 클립보드 오류 | 다른 프로그램이 클립보드를 점유 중입니다. 잠시 후 다시 시도 |
| 한글이 깨져 보임 | 스크립트가 UTF-8 BOM으로 저장되었는지 확인 |
| 업데이트 확인 실패 | 인터넷 연결과 회사망 방화벽(api.github.com) 확인 |

## 개발자 명령

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\KakaoRoomScheduler.ps1 -SelfTest
```

설정 스키마, 방 이름 필터, 창 제목 비교, 버전 비교, 가이드 내용을 점검하고 `SELFTEST_OK`를 출력합니다. 배포 스크립트가 자동으로 실행합니다.

---

## 사용 시 유의

수신에 동의한 분들이 있는 채팅방에서만 사용하세요. 반복적인 대량 발송은 카카오톡 이용 제한의 원인이 될 수 있으며, 그 책임은 사용자에게 있습니다.
